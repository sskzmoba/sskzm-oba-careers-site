# SSKZM OBA Careers & Mentors site: project rules

- Static site only (HTML/CSS/JS), no build step; must stay editable by non-developers in the GitHub web editor.
- Mobile-first; test at 375px width before publishing. Seniors use it: keep text large, buttons big, wording plain.
- Never render backend data with innerHTML; use OBA.el() (textContent) and OBA.safeUrl() for links.
- Never publish plain phone numbers, UPI IDs or member emails.
- Plain Indian English in all copy; no em or en dashes.
- Publish (merge to main) only with the General Secretary's go-ahead.
